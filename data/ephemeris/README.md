# Swiss Ephemeris Data

This directory contains locally installed Swiss Ephemeris binary data files.
The current set is:

- `sepl_18.se1` - planetary ephemeris
- `semo_18.se1` - lunar ephemeris
- `seas_18.se1` - asteroid ephemeris

The files are from the official `aloistr/swisseph` distribution (retrieved
through its jsDelivr mirror) and are covered by the Swiss Ephemeris
dual-license terms in `3rdparty/swisseph/LICENSE`.
