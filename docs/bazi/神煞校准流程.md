# 八字神煞校准流程

每校准一个神煞，必须同时完成以下四项，缺一不可：

1. **规则实现**：明确取法原点、扫描范围、命中条件、排除条件与冲突口径，写入八字核心计算模块。
2. **自动测试**：至少覆盖一条命中、一条不命中、关键边界和一张固定参考命盘；接口字段同步做契约测试。
3. **资料入库**：在 `config/bazi/shen_sha/` 下维护独立 JSON，记录典籍来源、原文、白话释义、固定表、分支规则和校勘备注。
4. **页面帮助**：命盘中的神煞名称必须可点击；点击后展示对应资料、当前命盘命中细节和来源口径，并支持键盘访问与关闭。

## 文件约定

- 文件名使用稳定内部 ID，例如 `lu_shen.json`。
- `calibration_status` 取 `draft`、`pending_confirmation` 或 `calibrated`。
- 典籍原文与工程解释分字段保存，不以工程判断改写原文。
- 有异文或疑似转录问题时保留用户确认版本，并写入 `editorial_notes`，不得静默修正。
- 八字神煞与紫微斗数、七政四余等体系同名概念必须明确隔离。
