## 实现约束

1. 主神煞、别名、子型和总论不得继续只用字符串混合表示。
2. 每次命中应保留依据、目标干支、来源规则和规则变体。
3. `draft` 或 `待确认` 规则不得标记为 `calibrated`。
4. 规则存在多个古籍版本时，必须在目录中显式选择版本。
