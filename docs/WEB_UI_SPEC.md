# ZhouYiLab Web UI 规范

版本：1.0  
适用范围：紫微斗数、奇门遁甲、八字及后续新增排盘工具。

## 1. 产品与设计原则

ZhouYiLab 是高信息密度的专业排盘工具。界面优先保证准确录入、快速扫描、跨盘比较和重复操作效率，不采用营销页式大标题、装饰性卡片或无业务含义的视觉效果。

- 风格：克制、清晰、专业，保留少量传统文化气质。
- 信息优先：排盘事实强于装饰，状态与来源必须可追溯。
- 一致性：共用导航、表单、标签、焦点态和响应式断点。
- 可访问性：键盘可达、焦点可见、触控目标不小于 44px。

## 2. 导航层级

### 一级导航

- 用于切换命理类型：紫微斗数、奇门遁甲、八字。
- 固定在页面顶部，整体相对视口水平居中。
- 当前项同时使用文字强调和 2px 下划线，不能只依赖颜色。
- 帮助、运行状态等工具放在右侧，不参与居中计算。

### 二级导航

- 位于一级导航下方，用于切换当前命理的内容视图。
- 与一级导航共同吸顶；切换不改变用户已填写的表单。
- 标签较多时允许导航容器内部横向滚动，当前项自动居中。
- 实验性或未投入使用的功能不进入生产导航。

## 3. 色彩

使用语义变量，不在组件中随意增加近似颜色。

| 语义 | 建议变量 | 用途 |
| --- | --- | --- |
| 页面背景 | `--bg` / `--paper` | 工作区底色 |
| 表面 | `--surface` | 导航、侧栏、数据单元 |
| 主文字 | `--ink` | 标题、关键数据 |
| 次文字 | `--muted` | 标签、说明、元数据 |
| 分隔线 | `--line` | 表格、区域边界 |
| 主操作 | `--jade` | 提交、一级当前状态 |
| 强调 | `--cinnabar` / `--accent` | 二级当前状态、关键提示 |
| 辅助强调 | `--gold` | 特殊状态和传统意象 |

普通正文与背景对比度至少达到 4.5:1。红、绿不得单独承担状态含义，必须配合文字或边框。

## 4. 字体与层级

- 正文：系统中文无衬线字体，避免依赖外部字体服务。
- 命盘主星、干支等展示数据可使用宋体或衬线字体。
- 页面正文基准为 15-16px，移动端表单控件不低于 16px。
- 紧凑面板标题 15-18px；只有页面主标题使用 `h1`。
- 正文行高 1.5-1.75；字距保持 `0`。

## 5. 布局与间距

- 桌面端输入侧栏统一为 320px，结果区使用剩余宽度。
- 主数据区域建议最大宽度 1040-1120px。
- 基础间距单位为 4px，常用间距为 8、12、16、24、32px。
- 页面区域不使用浮动卡片；卡片只用于重复数据项。
- 卡片圆角不超过 4px，边框优先于重阴影。

## 6. 表单与操作

- 输入框、下拉框、按钮最小高度 44px；主操作按钮建议 48px。
- 所有输入必须有可关联的 `label`，使用正确的输入类型。
- 分段控件用于少量互斥选项，复选框/开关用于布尔设置。
- 提交期间禁用按钮并显示加载状态；错误信息靠近表单展示。
- 数值单位固定显示在输入框右侧，不随内容移动。

## 7. 数据呈现

- 同类盘面保持固定网格尺寸，异步内容不能造成主要布局跳动。
- 标题、标签、数值建立清晰层级，标签不使用大字号。
- 表格在移动端改为卡片或提供局部横向滚动，不能撑宽页面。
- 状态标签使用稳定尺寸和边框，不在 hover 时缩放。
- 规则来源、计算口径和调试信息使用次级文本，不与结果抢层级。

## 8. 响应式规则

- 验证宽度：375、768、1024、1440px。
- 900px 以下侧栏转为顶部表单，结果区单列排列。
- 760px 以下品牌信息收紧，导航保持两层且不换成隐藏菜单。
- 页面本身不得产生横向滚动；复杂盘面只能在自身容器内处理。
- 固定导航不得遮挡正文或对话框。

## 9. 交互与动效

- hover/focus 只改变颜色、背景或边框，不改变组件尺寸。
- 微交互时长 150-200ms。
- 遵循 `prefers-reduced-motion`，关闭非必要平滑滚动和动画。
- 二级 Tab 必须同步更新 `aria-selected`、`tabindex` 与面板 `hidden` 状态。

## 10. 发布前检查

- 一级、二级导航当前态正确，滚动后仍可见。
- 键盘可通过“跳到主要内容”绕过固定导航。
- 所有可点击目标不小于 44px，焦点环清晰。
- 页面在四个规定宽度下无非预期横向滚动和文字重叠。
- 加载、空状态、错误状态和正常结果均已检查。
- 浏览器控制台无错误，自动化契约测试通过。
