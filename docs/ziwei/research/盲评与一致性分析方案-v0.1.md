# 紫微斗数星曜作用模型盲评与一致性分析方案 v0.1

> 状态：评分收集前冻结  
> 日期：2026-08-31  
> 对应实验：`experiment.lianzhen_qisha.qualitative_pilot`  
> 机器协议：`config/ziwei/research/blind_review_protocol.json`

## 1. 目的

本方案检验不同评分者在不知道案例原始编号、格局名称、模型方向和预期结果的情况下，能否对同一组廉贞七杀局部事实形成稳定的十一维方向判断。

本轮只检验构念和定性方向的一致性，不检验现实人生预测能力，也不产生星曜权重。

## 2. 评分材料

评分者可以看到：

- 匿名案例代码；
- 焦点宫地支；
- 星曜名称、物理位置、本宫或三方关系、亮度和四化；
- 受控四化刺激及“非完整命盘”的边界声明；
- 十一个维度的定义、纳入项、排除项和正负方向；
- 统一评分锚点。

评分者不能看到：

- `LQ-A` 至 `LQ-H` 原始编号；
- 案例名称和实验目的；
- “雄宿乾元格”等格局名称；
- 模型基础机制、方向假设、修正项及预期命中结果；
- 其他评分者的答案。

## 3. 评分量尺

每个案例的每个维度只能选择：

| 分值 | 定义 |
|---:|---|
| `-1.0` | 该维度受到明显抑制 |
| `-0.5` | 该维度受到轻度抑制 |
| `0.0` | 当前事实不足以判断方向，或正负作用大致并存 |
| `0.5` | 该维度受到轻度增强 |
| `1.0` | 该维度受到明显增强 |

每项评分必须填写简短依据。评分者确实无法判断时可以留空 `null`，不能为了完整率随意选择 `0.0`。`null` 表示缺失，`0.0` 是有效判断，二者必须严格区分。

## 4. 评分者要求

- 最少 3 名独立评分者，目标 5 名。
- 能理解本宫、三方、对宫、亮度和四化的基础概念。
- 不参与案例预期结果和模型方向假设的编写。
- 提交前独立完成，不讨论具体案例。
- 使用匿名评分者 ID，不在公开仓库保存真实身份。

本轮评分者可来自同一流派，以优先检验流派内部一致性。若混合不同流派，必须额外记录流派标签并分层报告，不能把流派差异当成随机误差。

## 5. 随机化与复现

盲评包由固定脚本和调用方提供的随机种子生成。相同配置版本与相同种子必须得到相同案例顺序和匿名代码。

研究负责人单独保存匿名代码与原始案例的映射。评分者获得的默认盲评包不包含答案映射。论文或报告应公开脚本、配置版本和最终采用的种子，但映射公开时间不得早于评分收集结束。

## 6. 主要一致性指标

每个维度分别计算区间型 Krippendorff's alpha，距离函数为评分差的平方。选择该指标是因为它允许多名评分者并能够处理缺失评分。

首轮预注册阈值：

| alpha | 处理 |
|---:|---|
| `>= 0.80` | 强一致，可进入候选参数讨论 |
| `>= 0.67` 且 `< 0.80` | 暂时可接受，必须复核分歧案例 |
| `< 0.67` | 不标定该维度，先修订定义、材料或评分说明 |

这些阈值当前属于项目预注册标准，不是本项目已经完成文献论证的结论。正式论文使用前必须补充方法学来源并重新评审。

## 7. 缺失与异常处理

1. 单个维度至少需要 3 名可用评分者才计算首轮 alpha。
2. 缺失值保持 `null`，不得自动填充均值或零分。
3. 重复评分者 ID、未知案例代码、非法分值和未知维度直接拒绝。
4. 排除评分者必须依据评分前已规定的条件，并保留审计记录。
5. 不因某位评分者降低一致性而在结果出来后将其删除。

## 8. 运行方式

生成默认盲评包：

```bash
python3 web/ziwei_blind_review.py packet --seed pilot-2026
```

研究负责人生成包含答案映射的版本：

```bash
python3 web/ziwei_blind_review.py packet --seed pilot-2026 --include-key
```

分析多个评分文件：

```bash
python3 web/ziwei_blind_review.py analyze \
  --packet blind-packet.json \
  --submission rater-a.json \
  --submission rater-b.json \
  --submission rater-c.json
```

盲评包、评分提交和分析结果默认输出 JSON，便于版本追踪和复现。

## 9. 进入下一阶段的条件

只有满足以下条件才讨论候选数值：

1. 至少 3 名合格评分者完成盲评。
2. 评分数据通过格式和匿名性校验。
3. 每个维度独立报告 alpha 和可用评分数。
4. 明确列出低一致性维度和分歧案例。
5. 不以总平均一致性掩盖单个维度失败。
6. 评分协议、配置和实验版本在收集开始后没有被静默修改。
