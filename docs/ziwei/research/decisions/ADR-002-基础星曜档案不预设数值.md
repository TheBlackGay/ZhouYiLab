# ADR-002：基础星曜档案不预设数值

> 状态：已接受  
> 日期：2026-08-31  
> 影响版本：研究模型 v0.1

## 决策

廉贞、七杀首版基础档案只保存属性、原始机制和维度方向假设，不保存基础分数、权重、系数或组合增量。

星曜原始机制沿用现有象义词典，标记为项目内已校订；从原始机制映射到十一维研究构念属于新的项目假设，统一标记为 `E5/proposed`。

## 原因

1. 当前尚未完成盲评，任何数值都缺少标定依据。
2. 先记录方向可以暴露构念重叠和逻辑冲突，又不会制造虚假精度。
3. 属性事实、原始机制、维度映射和未来数值应分别具有独立证据状态。
4. 后续可以比较专家方向判断，再决定哪些作用允许进入数值标定。

## 约束

1. `star_energy_profiles.json` 当前状态必须为 `qualitative_only`。
2. 维度假设只允许 `increase`、`decrease` 或 `context_dependent`。
3. 配置不得出现 `weight`、`score`、`coefficient`、`delta` 或基础向量数值。
4. 项目词典没有外部文献定位时，只能作为 `E5` 来源。
5. 用户提供的古诀缺少书名、版本和页码时记为 `E4`，补齐定位后再评审是否升级证据类型。

## 重新评审条件

廉贞七杀盲评方案、评分者要求和一致性指标全部冻结后，才允许提出首批候选数值。数值参数必须进入新的配置版本和决策记录，不得覆盖本档案的定性基线。
