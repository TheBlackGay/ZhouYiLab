# ADR-003：星曜交互保留并列信号

> 状态：已接受  
> 日期：2026-08-31  
> 影响版本：研究模型 v0.1

## 决策

星曜交互的基础机制、支持条件和失衡条件分别生成定性信号。多个信号允许同时存在，定性阶段不通过覆盖规则或总分将其合并为单一吉凶结论。

廉贞七杀首轮交互采用以下结构：

```text
廉贞、七杀同层同宫
→ 火制金的基础约束方向
+ 较高亮度信号
+ 三方四正同层化禄信号
+ 三方四正同层化权信号
+ 廉贞化忌信号
→ 按十一维分别保留作用方向与证据
```

## 原因

1. 同一组合可能同时提高执行能力与冲突风险，不能互相抵消后只剩一个总分。
2. 五行相克只说明约束方向，不足以证明约束有效或结果吉利。
3. 禄、权、落陷和化忌可能同时出现，需要保留各自证据供盲评和后续标定。
4. 在缺少数据时设定状态优先级，会把研究假设伪装成确定规则。

## 边界

1. 交互规则只在参与星曜属于同一盘层时成立。
2. 本规则只研究廉贞、七杀同宫，不把三合或对宫视为同一种交互。
3. “火制金为权”不直接生成财富、职位或富贵结论。
4. 格局名称仍由 `config/ziwei/patterns/` 识别，不作为交互输入。
5. 所有方向当前均为待验证假设，不含数值参数。
6. 按当前亮度表，廉贞七杀同宫只在丑、未出现，且均为廉贞利、七杀庙；同宫落陷不是可达案例，因此不配置为该交互的修正项。

## 后续

首轮盲评后比较以下模型：单星相加、单星加五行交互、加入亮度四化的完整定性模型。只有完整模型稳定优于基线时，才讨论交互数值和冲突合并策略。
