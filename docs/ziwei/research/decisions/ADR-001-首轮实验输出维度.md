# ADR-001：首轮实验输出维度

> 状态：已接受，冻结用于廉贞七杀首轮实验  
> 日期：2026-08-31  
> 影响版本：研究模型 v0.1

## 背景

研究协议最初提出八个输出维度。审查发现其中四组概念存在明显重叠：

1. “资源与财富”同时包含资源取得和长期保存，与“稳定与积累”重叠。
2. “权力与执行”无法区分拥有授权但行动较弱，或行动很强但缺乏权威的情况。
3. “学习与表达”无法区分内部认知和外部表达。
4. “情绪与欲望”无法区分情绪反应强度和目标欲望强度。

混合构念会让评分者对同一分值表达不同含义，降低盲评一致性，也使后续模型参数难以解释。

## 决策

首轮实验采用以下十一个维度：

1. 资源获取与调度 `resource_mobilization`
2. 权威与影响 `authority_influence`
3. 执行与行动 `execution_action`
4. 认知与规划 `cognition_planning`
5. 沟通与表达 `communication_expression`
6. 稳定与积累 `stability_accumulation`
7. 变化与开创 `change_initiative`
8. 关系与协作 `relationship_cooperation`
9. 情绪感受强度 `emotional_intensity`
10. 欲望与驱动力 `desire_drive`
11. 冲突与风险 `conflict_risk`

维度定义、纳入项、排除项及方向以 `config/ziwei/research/dimension_dictionary.json` 为唯一机器可读来源。

## 计分约束

1. 每个维度独立评分，范围为 `[-1.0, 1.0]`。
2. 首轮评分精度固定为 `0.1`，不得显示虚假的更高精度。
3. 正负只表示该维度的方向，不统一表示吉凶。
4. `emotional_intensity` 正值表示情绪反应更强，不表示情绪更好。
5. `conflict_risk` 正值表示风险暴露增加，与其他能力类维度方向不同。
6. 不生成未经定义的总分，也不将分值解释为现实概率。

## 后果

优点：

- 每个维度更接近单一构念；
- 可以表达星曜在不同方面的非同步变化；
- 评分分歧可以定位到具体构念；
- 计算轨迹更适合解释和复核。

代价：

- 评分工作量从八项增加到十一项；
- 首轮样本量和评分说明需要控制，避免评分疲劳；
- 维度之间仍可能存在经验相关性，需在试验后检查。

## 未采用方案

1. 保留八维：定义简洁，但混合构念无法满足后续标定要求。
2. 直接使用单一吉凶分：不可解释，且会掩盖能力增强与风险同时上升的情况。
3. 立即扩展为二十个以上细分维度：区分度较高，但首轮盲评成本过大。

## 重新评审条件

满足任一条件时重新评审本决策：

1. 两个维度在盲评中持续无法被评分者区分。
2. 关键星曜作用无法落入任何现有维度。
3. 评分者对某维度定义的一致性未达到预先登记的阈值。
4. 后续统计分析显示维度需要合并、拆分或改名。

任何变更必须新增决策记录并递增 `dictionary_version`，不得覆盖本次冻结定义。
