# ADR-005：盲评量尺与一致性指标

> 状态：已接受，评分收集前冻结  
> 日期：2026-08-31  
> 影响版本：盲评协议 v0.1

## 决策

1. 使用 `-1.0、-0.5、0.0、0.5、1.0` 五级锚点评分。
2. `null` 表示无法判断，`0.0` 表示有效的中性或方向并存判断。
3. 每个维度独立计算区间型 Krippendorff's alpha，使用平方差距离。
4. 至少 3 名、目标 5 名独立评分者。
5. `alpha >= 0.80` 为强一致，`0.67 <= alpha < 0.80` 为暂时可接受，低于 `0.67` 不进入数值标定。

## 原因

五级量尺比 `0.1` 步长更适合首轮专家判断，可以减少无依据的精细差异。Krippendorff's alpha 支持多评分者和缺失值，且可以逐维度报告。

评分值用于观察评分者判断，不是星曜模型权重。即使获得高一致性，也只能说明本轮构念与材料产生了稳定方向判断，不能证明现实预测有效。
