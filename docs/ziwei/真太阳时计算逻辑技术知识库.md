# 真太阳时计算逻辑技术知识库

> 本文只讨论真太阳时的概念、公式和计算方法，不依赖特定编程语言、软件或接口。文中采用的是适合一般时间校正的视太阳时近似方法，不等同于天文台级高精度历算。

## 1. 为什么需要校正

日常钟表时间是“平均太阳时”的统一约定。同一时区内，各地点的钟表时间相同，但由于经度不同，太阳实际运行到当地正南方的时刻并不相同；此外，地球公转轨道和自转轴倾角会造成真实太阳日长度的季节性差异。

出生地的太阳时可以拆成三步：

```text
标准时间 = 记录时间 - 夏令时
地方平均太阳时 = 标准时间 + 经度时差
真太阳时 = 地方平均太阳时 + 均时差
```

## 2. 三个时间概念

### 2.1 记录时间

出生证明、钟表或用户输入的原始时间。它可能受到夏令时影响，也可能只是当地时区的钟表时间。

### 2.2 标准时间

把记录时间还原为当地时区的标准时间。若记录时没有使用夏令时，则标准时间等于记录时间。

### 2.3 真太阳时

在标准时间的基础上，同时考虑地点经度差异和地球运行造成的均时差，得到更接近当地真实太阳位置的时间。

## 3. 需要的输入

| 输入 | 说明 |
|---|---|
| 记录日期时间 | 年、月、日、时、分、秒 |
| 出生地经度 | 东经为正，西经为负 |
| 标准经线 | 当前钟表时间所依据时区的中央经线 |
| 夏令时修正 | 若记录时间包含夏令时，需要扣除的分钟数 |

经度和标准经线必须使用同一方向约定。常见的北京时间以东经 120 度为标准经线。

## 4. 第一步：还原标准时间

如果记录时间是在夏令时制度下取得的，应先减去夏令时提前的时长：

```text
标准时间 = 记录时间 - 夏令时分钟数
```

例如记录时间为 09:05，夏令时为 60 分钟：

```text
标准时间 = 09:05 - 60 分钟 = 08:05
```

如果没有夏令时，夏令时修正为 0。

## 5. 第二步：计算经度时差

地球自转一周为 360 度、24 小时，因此：

```text
360 度 / 24 小时 = 15 度 / 小时
1 度 = 4 分钟 = 240 秒
```

经度时差公式：

```text
经度时差（秒） = (出生地经度 - 标准经线) × 240
```

计算后通常四舍五入到整数秒。

### 5.1 符号判断

- 出生地在标准经线以东：经度时差为正，时间向后加；
- 出生地在标准经线以西：经度时差为负，时间向前减；
- 出生地正好位于标准经线：经度时差为 0。

### 5.2 示例

以标准经线 120 度为基准：

**杭州，东经 120.3 度**

```text
(120.3 - 120.0) × 240 = +72 秒
```

**成都，东经 104.066 度**

```text
(104.066 - 120.0) × 240 = -3824.16 秒
约 -3824 秒，即提前约 63 分 44 秒
```

## 6. 第三步：计算均时差

经度时差只能解决“地点不同”的问题，均时差解决“真实太阳日与平均太阳日长度不同”的问题。均时差会随一年中的日期和当天时刻变化。

### 6.1 计算年内日序

把日期转换为 `day_of_year`：1 月 1 日为第 1 天。

闰年判断规则：

```text
能被 4 整除且不能被 100 整除，或能被 400 整除
```

闰年 2 月以后需要比平年多计 1 天。

### 6.2 计算分数小时

```text
分数小时 = 小时 + 分钟 / 60 + 秒 / 3600
```

### 6.3 计算角度参数

设一年总天数为 `N`，平年 `N = 365`，闰年 `N = 366`：

```text
γ = 2π / N × (day_of_year - 1 + (分数小时 - 12) / 24)
```

使用当天中午作为相位参考点。

### 6.4 NOAA 均时差近似式

先计算分钟值：

```text
E = 229.18 × (
    0.000075
  + 0.001868 × cos(γ)
  - 0.032077 × sin(γ)
  - 0.014615 × cos(2γ)
  - 0.040849 × sin(2γ)
)
```

再换算为秒：

```text
均时差（秒） = E × 60
```

实际使用时可四舍五入到整数秒。

### 6.5 均时差的符号

本文约定：

- 均时差为正：真太阳时领先平均太阳时；
- 均时差为负：真太阳时落后平均太阳时。

不同资料可能采用相反定义，使用前必须确认符号口径，不能直接混用。

## 7. 合并校正

完整校正量为：

```text
总校正量（秒）
  = -夏令时分钟数 × 60
  + 经度时差（秒）
  + 均时差（秒）
```

最终时间：

```text
真太阳时 = 记录时间 + 总校正量
```

更推荐按以下中间步骤理解：

```text
1. 记录时间 - 夏令时 = 标准时间
2. 标准时间 + 经度时差 = 地方平均太阳时
3. 地方平均太阳时 + 均时差 = 真太阳时
```

均时差应使用扣除夏令时后的标准时间来计算。

## 8. 跨日、跨月和跨年

时间加减必须同步处理日期：

- 校正后小时小于 0：回到前一天；
- 校正后超过 24 小时：进入后一天；
- 月初、月末要正确处理月份变化；
- 1 月 1 日向前校正可能进入上一年；
- 闰年 2 月的天数不同于平年。

判断是否跨日时，应比较原始记录日期和最终真太阳时的年月日，而不只是比较小时是否变化。

## 9. 完整示例

假设：

```text
记录时间：1994-12-08 09:05:00
出生地经度：120.3 度
标准经线：120.0 度
夏令时：0 分钟
均时差：+482 秒（示例值）
```

计算：

```text
夏令时修正：0 秒
经度时差：(120.3 - 120.0) × 240 = +72 秒
均时差：+482 秒
总校正量：0 + 72 + 482 = +554 秒
```

554 秒等于 9 分 14 秒，因此：

```text
真太阳时 = 1994-12-08 09:14:14
```

## 10. 如何理解结果

建议始终保留以下信息，而不是只显示一个校正后的时刻：

1. 原始记录时间；
2. 扣除夏令时后的标准时间；
3. 经度时差及其正负号；
4. 均时差及其正负号；
5. 总校正量；
6. 最终真太阳时；
7. 是否跨越了日期边界。

这样可以区分“地点造成的差异”和“季节造成的差异”，也便于复核争议结果。

## 11. 常见错误

### 错误一：把时区中央经线当成出生地经度

标准经线是钟表系统的基准，出生地经度是实际地点，两者通常不同。经度时差正是由二者之差产生的。

### 错误二：忽略夏令时

夏令时是钟表人为提前的时间，必须先还原，否则后续所有校正都会整体偏移。

### 错误三：经度方向写反

东经为正、西经为负，并且要统一使用“出生地经度减标准经线”的顺序。

### 错误四：只校正时分，不处理日期

西部地区或午夜附近的时间，校正后可能落到前一天；东部地区也可能在深夜跨到后一天。

### 错误五：混淆均时差定义

不同教材对均时差的定义可能互为相反数。必须先确认公式采用的是“真太阳时减平均太阳时”，还是相反定义。

## 12. 精度与适用范围

NOAA 分数年公式是工程上常用的近似式，优点是计算简单、连续、无需全年查表，适合一般时间校正、历法研究和需要可解释过程的排盘场景。

它不是完整的天文历算模型。若研究要求达到天文观测级精度，还需要进一步考虑地球轨道参数、岁差、章动、地球自转不均匀等因素，并明确使用的时间尺度（UTC、UT1、TT 等）。

## 13. 一句话总结

真太阳时的计算顺序是：**先把记录时间还原为标准时间，再按出生地相对标准经线的经度差校正，最后叠加随日期变化的均时差，并正确处理跨日。**
