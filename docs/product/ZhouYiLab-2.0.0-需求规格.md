# ZhouYiLab 2.0.0 需求规格

## 版本目标

将大六壬从“可运行的排盘页面”提升为“普通用户可完成、初学者可理解、专业用户可核对”的基础产品。

## 用户流程

```text
选择问题类型 → 输入时间与历法 → 确认时间口径 → 开始起课
→ 查看本课重点 → 阅读三传起因/发展/结果 → 按需展开专业详情
```

## 功能需求

### DLR-201 输入与时间

- 支持公历、农历和闰月。
- 支持一键填入当前时间和示例时间。
- 明确时区、标准时间、子时换日、月将切换和分钟是否参与计算。
- 日期非法、农历不存在或计算失败时给出可操作错误信息。
- 提交期间禁用按钮并显示计算状态，避免重复请求。

### DLR-202 问题上下文

- 提供问题类型：感情、工作、财运、出行、健康、其他。
- 提供可选问题描述，不影响当前核心排盘算法。
- 结果页保留本次问题上下文，便于截图和复盘。

### DLR-203 双模式结果

- 默认进入小白模式。
- 小白模式显示：八字、月将、贵人、本课重点、三传流程、基础说明。
- 专业模式显示：四课、三传详情、天地盘、神将、遁干、六亲、旬空、神煞和卦体。
- 小白模式不直接给出确定性吉凶结论。

### DLR-204 术语帮助

- 为四课、三传、初传、中传、末传、月将、贵人、课式、六亲、旬空提供解释。
- 每个解释注明“当前页面采用的口径”。
- 帮助内容支持键盘访问和移动端阅读。

### DLR-205 接口契约

- 保留现有 `ba_zi`、`yue_jiang`、`gui_ren`、`is_day`、`si_ke`、`san_chuan` 字段。
- 继续提供 `tian_di_pan`、`shen_sha`、`gua_ti` 结构化字段。
- 新字段只做向后兼容新增，不静默改变现有字段语义。
- API 响应包含算法版本和规则口径标识。

## 非功能需求

- 375px、768px、1440px 页面均不出现横向滚动。
- 键盘可完成输入、提交、切换模式和打开帮助。
- 起课主按钮触控区域不小于 44px。
- 正常起课响应时间目标小于 3 秒，超时给出重试提示。
- 不把用户问题描述写入服务日志。

## 验收案例

1. 新用户使用默认示例，在 1 分钟内完成起课，并能说明三传三阶段含义。
2. 农历闰月输入能够正确提交，非闰月输入不显示误导性闰月状态。
3. API 返回的四柱不出现 `[object Object]`，天地盘恰好包含 12 个位置。
4. 三传包含初、中、末传以及遁干和六亲详情。
5. 计算失败时页面保留用户输入，并显示可理解的错误信息。
6. 小白模式和专业模式在同一份排盘数据上切换，不重复请求接口。

## 明确不做

- 2.0.0 不重写大六壬核心取课算法。
- 2.0.0 不引入自动断语或 AI 结论。
- 2.0.0 不实现完整十二宫 SVG/Canvas 盘面，该内容属于 2.1.0。
- 2.0.0 不宣称大六壬算法已完成跨门派校准。
