# ZhouYiLab 2.x 版本路线图

> 目标：每个版本都能独立运行、验证、部署和回退。2.x 优先把大六壬做成可交付样板，再将成熟能力推广到其他术数。

## 版本总览

| 版本 | 主题 | 用户价值 | 交付门槛 |
| --- | --- | --- | --- |
| 2.0.0 | 大六壬易用基础版 | 小白能完成起课并理解三传 | 快速模式、专业模式、输入口径、术语帮助、结构化接口 |

## 共同发布门槛

每个版本发布前必须满足：

- 版本分支、版本号、变更说明一致。
- 主流程至少有一条浏览器或接口验收测试。
- 已知边界案例有自动化回归测试，或明确记录为未解决风险。
- Dockerfile 和 Compose 可以从干净环境构建或拉取启动。
- API 不兼容变更有迁移说明；兼容新增字段不改变旧字段语义。
- README 包含启动、升级、回退和健康检查命令。
- 工作区干净，提交可回退。

## 依赖顺序

```text
2.0.0 输入与解释基础
        ↓
2.1.0 盘面可视化
        ↓
2.2.0 规则解释
        ↓
2.3.0 案例校准
        ↓
2.4.0 跨术数统一
```

## 暂不纳入 2.x

- 大规模新增术数模块。（2026-09-20 更新：新增术数按 3.x 系谱推进——**梅花易数已切 `r_3.0.0` 分支**，M1 内核+CLI、M2 平台接入已落地，M3 案例库、M4 画像在 3.0.0 线内排期）
- 未经案例校准的确定性断语。
- 让 AI 直接生成或修改排盘事实。
- 用户账号、社交、付费等与排盘可信度无关的复杂业务。

## 西洋占星生活化解析专项计划

西洋占星当前已经具备本命盘、结构化信号和证据分析能力。本专项把“本命盘 + 行运”逐步转化为可验证的日常生活提示，独立于大六壬版本序列推进。

| 迭代 | 主题 | 依赖 | 交付门槛 |
| --- | --- | --- | --- |
| A0 | 设计与契约冻结 | 现有 Astro API | 设计方案、字段字典、规则边界和样例 fixture 评审通过 |
| A1 | 行运计算与事实包 | A0、Swiss Ephemeris | `astro-transit-structured/1.0` 稳定输出，固定日期和时区回归通过 |
| A2 | 生活领域信号规则 | A1 | 已完成：感情、财富、事业、学习、人际规则均带证据和版本 |
| A3 | 日运解析包 | A2 | 已完成：`astro-daily-reading/1.0` 可生成摘要、重点、建议和避免，事实可追溯 |
| A4 | 日运页面 MVP | A3 | 日期浏览、领域卡片、证据展开和移动端验收通过 |
| A5 | 关注度校准 | A3、A4 | 分数语义明确，支持无分数降级，不解释为现实概率 |
| A6 | 周/月视图 | A1-A5 | 日级信号聚合稳定，峰值和持续时间可回溯 |
| A7 | 幸运信息与分享 | A4、规则校准 | 附加内容不影响主解析可信度，分享内容可复现 |
| A8 | 规则校准与发布 | A1-A7 | 案例、回归、文档、版本和回退方案齐全 |

详细字段、页面和规则设计见：[西洋占星生活化解析设计方案](西洋占星生活化解析设计方案.md)。A1、A2、A3 已完成，当前待实施项为 A4：日运页面 MVP。
