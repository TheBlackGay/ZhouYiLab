# ZhouYiLab 2.x 版本路线图

> 目标：每个版本都能独立运行、验证、部署和回退。2.x 优先把大六壬做成可交付样板，再将成熟能力推广到其他术数。

## 版本总览

| 版本 | 主题 | 用户价值 | 交付门槛 |
| --- | --- | --- | --- |
| 2.0.0 | 大六壬易用基础版 | 小白能完成起课并理解三传 | 快速模式、专业模式、输入口径、术语帮助、结构化接口 |
| 2.1.0 | 天地盘可视化版 | 用户能直观看懂盘面位置 | 十二宫盘、关键标记、移动端布局 |
| 2.2.0 | 规则解释版 | 用户能知道结果如何推导 | 生克关系、三传取法、课式和神煞解释 |
| 2.3.0 | 案例校准版 | 专业用户能验证算法稳定性 | 案例库、回归测试、差异报告、校准状态 |
| 2.4.0 | 跨术数统一版 | 同一时间在不同术数间可比较 | 统一时间口径、输入格式、API 元数据 |

## 共同发布门槛

每个版本发布前必须满足：

- 版本分支、版本号、变更说明一致。
- 主流程至少有一条浏览器或接口验收测试。
- 已知边界案例有自动化回归测试，或明确记录为未解决风险。
- Dockerfile 和 Compose 可以从干净环境构建或拉取启动。
- API 不兼容变更有迁移说明；兼容新增字段不改变旧字段语义。
- README 包含启动、升级、回退和健康检查命令。
- 工作区干净，提交可回退。

## 依赖顺序

```text
2.0.0 输入与解释基础
        ↓
2.1.0 盘面可视化
        ↓
2.2.0 规则解释
        ↓
2.3.0 案例校准
        ↓
2.4.0 跨术数统一
```

## 暂不纳入 2.x

- 大规模新增术数模块。
- 未经案例校准的确定性断语。
- 让 AI 直接生成或修改排盘事实。
- 用户账号、社交、付费等与排盘可信度无关的复杂业务。
