## 3. 起卦口径（内核输出即事实，口径全部进 rule_profile）

时间起卦（《梅花易数》年月日时起卦法）：

```
上卦 = (年支序 + 农历月数 + 农历日数) mod 8    （余 0 作 8）
下卦 = (年支序 + 农历月数 + 农历日数 + 时支序) mod 8（余 0 作 8）
动爻 = (上式总数) mod 6                        （余 0 作 6）
先天卦数：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8
```

- 年支序以**立春**为岁首（复用统一八字历法层年柱口径，不另起炉灶）；
- 体用：动爻所在经卦为**用**，另一为**体**；互卦为事之中程、变卦为终结（沿用
  传统四段式，仅作为结构化字段输出，不作断语）；
- 输出契约 `meihua-plate/1.0`：起卦时间 + 农历取数三元 + 本/互/变三卦（名/码/
  宫/卦数）+ 体用两卦五行 + 各自月令旺衰 + 体用生克五态判词（生/克/比和，
  纯关系描述）+ meta.rule_profile。

## 6. 风险登记（预先声明）

- 梅花诸刻本起卦公式无歧义（年月日时数），但**取数用的农历日**依赖历法层正确性——
  已由统一八字历法层多轮案例背书，风险低；
- 象义字典为主观整理物：字段全部过 D8 source_ref（出处刻本可空则标"通行整理"），
  与"事后可追溯"铁律一致；
- 体用生克五态判词不得包装成吉凶（M1-M3 期间 calibration=pending，禁断语词测试
  照抄 dlr/bazi/liuyao 三件套）。
